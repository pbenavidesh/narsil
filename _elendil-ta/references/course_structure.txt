# Course Structure — Time Series Forecasting at ITESO

## Progressive Narrative

The course builds ONE forecasting approach across 4 modules and 17 lessons, adding
complexity at each module. Every new method must justify itself by beating the
previous baseline.

Lessons are identified by module and lesson number (1.0, 1.1, ... 4.4), matching the
course site sidebar. Week numbers are deliberately omitted — they shift every term,
the lesson structure does not.

---

## Module 1: Forecasting models based on decomposition methods
*"Getting data ready and establishing a baseline"* | FPP3 Ch. 2, 3, 5

- 1.0 Introduction — course overview, workflow, and expectations
- 1.1 R, tsibble, and Time Series — packages, tsibble basics, visualization
- 1.2 Time Series Decomposition — trend-cycle, season, remainder; STL
- 1.3 Forecasting Foundations — transformations, train/test split, benchmark
  methods (MEAN, NAIVE, SNAIVE, Drift), accuracy metrics
- 1.4 Model Diagnostics and Advanced Forecasting — residual diagnostics,
  Ljung-Box, and `decomposition_model()`

**Module deliverable:**
```r
decomposition_model(STL(y), SNAIVE(season()), RW(drift = TRUE))
```
This is **the baseline**. Every future model is compared against it.

Key concepts introduced: train/test split, residual diagnostics, accuracy metrics
(MAE, RMSE, MAPE, MASE, RMSSE)

---

## Module 2: Adding ETS and ARIMA filters
*"Replacing naive methods with statistical filters"* | FPP3 Ch. 8, 9

- 2.1 Exponential Smoothing — error, trend, season components
- 2.2 Stationarity & Differencing — unit roots, differencing, ACF/PACF
- 2.3 ARIMA Models — identification, fitting, seasonal ARIMA
- 2.4 Modular Forecasting: Mixing ETS and ARIMA — swapping components inside
  the decomposition baseline

**Module deliverable:**
```r
# Option A: ETS inside decomposition
decomposition_model(STL(y), ETS(season_adjust ~ error("A") + trend("N") + season("N")))

# Option B: Full ARIMA (replaces decomposition)
ARIMA(y)  # with possible seasonal terms
```

Key concepts: ACF/PACF interpretation, unit root tests, AIC/BIC model selection,
information criteria, seasonal ARIMA (P,D,Q)

---

## Module 3: Regression and exogenous variables
*"Your model now knows what's happening in the world"* | FPP3 Ch. 7, 10, §12.2, Ch. 13

- 3.1 Practical Issues — outliers, missing values, short series, forecast
  constraints (FPP3 Ch. 13)
- 3.2 Linear Regression Models — `TSLM(y ~ trend() + season())`, uses seasonal
  **dummies**, not Fourier; adding external regressors
- 3.3 Dynamic & Harmonic Regression — motivation: TSLM residuals show
  autocorrelation → need ARIMA errors
  - `ARIMA(y ~ xreg + PDQ(0,0,0))` — regression with ARIMA errors
  - Harmonic regression: `ARIMA(y ~ fourier(K=k) + PDQ(0,0,0))`
- 3.4 Prophet — `prophet(y ~ season("week") + season("year"))` (FPP3 §12.2)

**Critical distinction**: TSLM uses seasonal dummies; harmonic regression uses
Fourier terms. This contrast is pedagogically important — don't conflate them.

Key concepts: spurious regression, cointegration intuition, lagged regressors,
distributed lag models, Fourier terms for complex seasonality

---

## Module 4: Forecasting at scale
*"Making models production-ready"* | FPP3 §5.10, Ch. 11, §12.1, §12.5, §13.4

- 4.1 Complex Seasonality (FPP3 §12.1)
  - Multiple `season()` calls in STL for sub-daily data
  - Fourier + ARIMA errors for large/non-integer periods
- 4.2 Bootstrapping, Bagging & Model Combinations (FPP3 §12.5, §13.4)
  - `generate()`, bootstrapped prediction intervals, bagged forecasts,
    ensemble methods
- 4.3 Time Series Cross-Validation (FPP3 §5.10)
  - `stretch_tsibble()`, rolling-origin evaluation, why random CV is wrong
    for time series
- 4.4 Hierarchical & Grouped Forecasting (FPP3 Ch. 11)
  - `aggregate_key()`, `reconcile()`, MinT, BU, TD approaches

## Grading Philosophy

- Baseline model (STL + SNAIVE + Drift) is the scoring **threshold**
- Teams beating the baseline score on a linear scale
- Teams failing to beat it are capped
- Metrics: MAPE for global forecasting, RMSSE for hierarchical
